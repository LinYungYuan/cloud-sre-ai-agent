RCA WORKER · TARGET ARCHITECTURE

從可驗證的 telemetry 到可追溯的根因分析

這版把現有的 deterministic MCP 收集邊界保留下來，並在 evidence 持久化之後加入三個無工具的 Specialist AI。RCA AI 只接收少量、結構化且引用 evidence ID 的 observations。

01 · ARCHITECTURE

RCA Worker 元件架構

實線節點為現有基礎；橘色節點是需要補上的 Specialist AI 分析層。MCP 工具、scope 與 schema 驗證仍由 deterministic code 控制。

02 · PROCESS

端到端 RCA Worker 流程

四條泳道分開呈現 orchestration、資料收集、持久化與 AI 推理責任；橘色步驟是新增的壓縮分析階段。

這次架構調整的核心

Collector 繼續負責安全查詢與保存；Specialist AI 僅分析已保存且屬於自己的 evidence，輸出有限、可驗證的 observations；RCA Agent 不再只看到固定摘要。

保持不變的邊界

Pub/Sub job、Rule Router、read-only MCP manifest、scope／deadline、evidence provenance、報告狀態與 Operator API 契約可沿用。
